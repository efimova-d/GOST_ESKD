# GOST_ESKD — библиотека компонентов KiCad (УГО по ГОСТ ЕСКД + посадочные места)

Библиотека подключается к проектам как **git-сабмодуль** и содержит:

| Файл / папка | Содержимое |
|---|---|
| `GOST_ESKD.kicad_sym` | 22 символа: УГО компонентов по ГОСТ ЕСКД, символы питания и невидимый `PWR_FLAG` |
| `GOST_ESKD.pretty/` | 12 посадочных мест, используемых в проекте |
| `docs/GOST_ESKD_catalog.pdf`, `docs/catalog.png` | каталог всех УГО (отрисован kicad-cli) |
| `docs/size_check.txt` | автоматическая проверка размеров УГО (63 параметра) |

Общие правила: толщина линий УГО равна толщине линий связи (ГОСТ 2.721-74, примечание к табл. 7);
шрифт надписей — «GOST type B», размер 2,5 мм (ГОСТ 2.304); все выводы на сетке 2,54 мм.
Номера выводов совпадают со стандартными посадочными местами (диод: 1 — катод; MOSFET: 1 — З, 2 — С, 3 — И).
В каждом символе есть поля `Manufacturer_Part_Number` и `Manufacturer`.

## Посадочные места

Посадочные места соответствуют стандартным библиотекам KiCad
(лицензия CC-BY-SA 4.0 с исключением для производимых изделий). 3D-модели подключаются из стандартной
установки KiCad через `${KICAD10_3DMODEL_DIR}`.

## Подключение к проекту

```bash
git submodule add https://github.com/efimova-d/GOST_ESKD.git lib/GOST_ESKD
```

В папке проекта — таблицы библиотек с относительными путями:

```
sym-lib-table:  (lib (name "GOST_ESKD")(type "KiCad")(uri "${KIPRJMOD}/lib/GOST_ESKD/GOST_ESKD.kicad_sym"))
fp-lib-table:   (lib (name "GOST_ESKD")(type "KiCad")(uri "${KIPRJMOD}/lib/GOST_ESKD/GOST_ESKD.pretty"))
```
